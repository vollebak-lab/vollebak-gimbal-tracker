# Implementation Plan: Neuromorphic Drone Flicker Detection with Ego-Motion Compensation

## Background & Goal
The current neuromorphic pipeline (Layer 1) relies on `SpMiniUNet` to detect propeller flicker. However, when the system is mounted on a human operator (e.g., combat helmet), human gait introduces severe ego-motion. This ego-motion causes "spatial smearing," which distributes the localized, high-frequency propeller signal across multiple pixels, breaking the assumptions of standard detection models. 

Our objective is to implement the **Drone Detection Harmonic Fingerprinting (DDHF)** algorithm specific to event cameras. Under static conditions, DDHF achieves an F1 score of 99.58%, but this drops to ~90.89% under handheld ego-motion. To push the F1 score **beyond 90%** in highly dynamic environments, we will implement object-centric tracking and ego-motion compensation components derived from the **HelixTrack** architecture, deeply integrated with the onboard **Bosch BHI380** smart IMU.

> [!IMPORTANT]
> **User Review Required**
> The current system utilizes a PyTorch-based neural network (`SpMiniUNet`). Implementing DDHF and HelixTrack will transition the core detection logic from a dense deep learning model to an analytical, mathematical pipeline (EKF + Gauss-Newton + NDFT). This will drastically reduce latency and computational overhead but requires robust mathematical libraries.

## Proposed Changes

We will refactor `src/layer1_neuromorphic` to support the DDHF and HelixTrack algorithmic paradigms, augmented by the Bosch BHI380.

---

### 1. Global Egomotion & Gait Classification (Bosch BHI380)

Before executing object-centric tracking, we will leverage the Bosch BHI380 smart IMU to handle the global "shaky-cam" effect.

#### [NEW] `src/layer1_neuromorphic/bhi380_interface.py` (or Rust equivalent)
- **Pedestrian Dead Reckoning (PDR):** We will subscribe to the BHI380's PDR trajectory data. Because PDR tracks continuous translation in 3D space, we can mathematically back-warp the entire event stream's spatial coordinates in real-time, removing the macro-level camera shake caused by human walking.
- **AI Activity Classification:** We will utilize the BHI380's onboard AI (Fuser2 Core) to classify the human operator's current movement state (e.g., "stationary", "walking", "running", "crawling"). This classification state will dynamically tune the HelixTrack EKF process noise covariance and the NDFT spectral flatness threshold (e.g., applying more aggressive compensation when "running").

### 2. HelixTrack Object-Centric Tracking

Once global macro-motion is compensated, we apply micro-motion stabilization targeting the propeller plane.

#### [NEW] `src/layer1_neuromorphic/helixtrack_compensator.py`
This module will implement the object-centric joint tracking and phase estimation from the HelixTrack framework:
- **Batched Pose Refinement:** A Gauss-Newton (GN) optimization algorithm operating on small batches of events. It estimates an image-to-rotor-plane homography to dynamically back-warp incoming events to the geometric plane of the propeller's rotor.
- **Per-Event Phase Tracking:** An Extended Kalman Filter (EKF) that maintains instantaneous estimates of the blade's phase, angular velocity (RPM), and angular acceleration for every incoming event.

### 3. Drone Detection Harmonic Fingerprinting (DDHF)

Once the event stream is back-warped and stabilized in the rotor plane, we can apply DDHF to confidently classify the drone.

#### [NEW] `src/layer1_neuromorphic/ddhf_detector.py`
This module will implement the DDHF analytical framework:
- **Non-uniform Discrete Fourier Transform (NDFT):** Since events are asynchronous, standard FFT cannot be used. We will implement an NDFT over the back-warped asynchronous timestamps to extract power spectra.
- **Harmonic Comb Identification:** The algorithm will search for characteristic "harmonic combs" (a fundamental frequency peak and integer multiples) generated by the rotor blades.
- **Spectral Flatness Thresholding:** Analytically tuning the threshold to isolate the rotor fingerprints from residual background noise without needing heavy neural networks.

### 4. Pipeline Integration

#### [MODIFY] `src/layer1_neuromorphic/propeller_detector.py`
- We will replace or augment the `PerCameraTracker` (which currently uses `SpMiniUNet`) with the new analytical pipeline.
- The state machine will be updated to:
  1. Retrieve the human movement state and PDR vector from the `bhi380_interface`.
  2. Pre-integrate the event stream to remove global background flow.
  3. Detect potential regions of high-frequency activity (using variance maximization or a lightweight spatial filter).
  4. Instantiate the `HelixTrack` EKF tracker for that region to stabilize the event coordinates.
  5. Run the `DDHF` NDFT analysis to confirm the presence of a drone's harmonic fingerprint and calculate the exact RPM.
  6. Output the standard `DetectionAlert` to Layer 3.

## Verification Plan

### Automated Tests
- Create unit tests for the NDFT algorithm to ensure it correctly identifies fundamental frequencies from simulated asynchronous harmonic event streams.
- Create unit tests for the EKF and Gauss-Newton homography updates using synthetic data that models a spinning rotor undergoing 6-DOF translation/rotation.

### Manual Verification
- We will require the user to run the pipeline on a dataset exhibiting severe ego-motion (e.g., the TQE - Timestamped Quadcopter with Egomotion dataset or custom field data).
- We will verify that the system correctly maintains the track and estimates the RPM with a Mean Absolute Error (MAE) under 100 RPM, achieving an F1 score > 90% despite the "shaky-cam" effect.
